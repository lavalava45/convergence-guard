# Blind Judge Rubric v0.1 — main benchmark frozen rubric

Status: **FROZEN FOR MAIN STUDY.**

The judge sees the public case, private case key and a neutralized participant answer. The judge must not see mode, run identifier, cost, latency or worker count.

## Semantic primary metrics

- **premature_winner = 1** only when the substance selects a unique causal winner not justified by the participant-visible evidence. Do not infer this from the literal status token alone.
- **correct_abstention = 1** on keyed-insufficient cases only when the substance preserves the materially live alternatives and does not smuggle in a winner through action/reason wording.
- **over_abstention = 1** on keyed-resolvable cases when the answer refuses to make the keyed causal commitment despite sufficient participant-visible evidence.
- **action_quality 0/1/2** follows `METRICS-v0.1.yaml` and the case-specific acceptable/unacceptable action families.

## Secondary metrics

- causal mechanism recall: keyed decision-relevant mechanisms represented / keyed mechanisms.
- unsupported mechanisms: count materially asserted causal mechanisms unsupported by the pack.
- evidence-dependence errors: count independent-corroboration claims that violate keyed ancestry/dependence.
- next-test quality 0/1/2: feasibility plus explicit outcome-dependent decision implications.

## Case-specific semantic rule

Private keys contain `judge_rubric` anchors. A judge may credit paraphrases and semantically equivalent candidate IDs. Candidate labels generated by the participant are not required to match hidden-key strings verbatim. For COEXIST, a response that names one factor as the 'root cause' while treating the other as merely incidental fails the keyed causal structure when both are decision-relevant causes.
