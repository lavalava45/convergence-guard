# M08 — Optical-resin haze investigation

Orchid Materials manufactures an optical resin on three production lines. Customers report haze in a subset of finished batches. Early incident reports focused on a new raw-material supplier lot, but the facility also had maintenance, cleaning, and scheduling changes in the same period.

You are given a frozen incident file assembled from operations, QA, maintenance, supplier, and laboratory records. The prompt intentionally does not enumerate a complete hypothesis list.

Determine the best-supported causal conclusion, the immediate containment/corrective action, and the minimum next test that could materially change that conclusion.

Constraints:

- base conclusions only on the frozen evidence pack;
- distinguish independent evidence from summaries that reuse the same upstream source;
- do not use the open web;
- do not assume facts outside the supplied evidence;
- avoid unnecessary supplier-wide or plant-wide shutdown actions if the evidence supports narrower containment.

Return the required normalized final-answer object.
